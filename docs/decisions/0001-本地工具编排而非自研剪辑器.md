# ADR 0001：本地工具编排，而非自研剪辑器

- 状态：已接受
- 日期：2026-10-03

## 背景

目标是改善个人视频制作工作流。调研了 GitHub 上的 ChatCut 生态：

- `ChatCut-Inc/agent-plugin`（920★）：闭源 SaaS 的 MCP 插件，只有 skill 层开源
- `0xsline/OpenChatCut`（2.1k★）：完整开源剪辑器（React + Remotion + Electron）
- `ArtCog/chatmonteur`：CLI 编排的口播流水线（ffmpeg/whisper/auto-editor）
- `cellinlab/ChatCutPro`：原型

自研同类编辑器工程量巨大，且与"改善自己的工作流"这一目标无关。

## 决策

采用**本地工具 + 脚本编排**路线：

1. 每个环节选用成熟的本地开源工具，不做重复造轮子
2. 用脚本把工具串成流水线，脚本本身入 Git 管理
3. 剪辑精修交给现成软件（剪映 / Premiere / 达芬奇），本仓库只负责其上游环节

## 后果

- ✅ 每个环节可独立验收、独立替换
- ✅ 零成本、可离线、素材不出本地
- ⚠️ 没有统一 GUI，靠命令行/脚本驱动
- ⚠️ 需要自己维护工具间的格式衔接（转码、命名、目录约定）

## 被否决的方案

- 自研时间线编辑器：投入产出比过低
- 纯云端方案（如直接用 ChatCut）：素材出本地、按量付费、不可编排
