# vibecut

个人视频制作的**本地工作流**：把各环节最好的工具在本地组装起来，用脚本串成可重复执行的流水线。

## 目标

- 覆盖视频制作环节：转写+字幕、智能粗剪、配音/音乐、画面生成、素材管理、格式转换/压制
- 工具以**本地免费优先**（RTX 4060 8GB 可跑的模型），必要时才用付费 API
- 每个环节都是可独立调用的命令/脚本，可单独使用，也可串联

## 非目标（明确不做）

- ❌ 不开发时间线剪辑器 / ChatCut 类产品（已有大量成熟开源实现，见 `docs/research/`）
- ❌ 不做云端服务、不做多人协作
- ❌ 不追求大而全，只做自己工作流真正用得到的环节
